# bilingua-htmlcore

The HTML engine under `bilingua-html` and `bilingua-serverpages`: a port of the Localization OS HTML filter
(`app/filters/html_filter.py`: tokenizer, block units with inline tags, `translate="no"`, accessibility and page
metadata attribute units, the target-language declaration) and its browser guard (`app/filters/html_guard.py`: what
an HTML5 browser makes of a page, the strict attribute escaping and the export check), token for token.

Plumbing for Bilingua's own HTML-family filters, not a public API: its modules are `#[doc(hidden)]` and change in
lockstep with those crates.

`src/entities.rs` is generated by `tools/gen_entities.py` from Python's `html.entities` tables.
